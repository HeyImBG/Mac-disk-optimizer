# CLAUDE.md

Rules for any coding thread working in this repo. Keep PRs small and follow these exactly.

## What this is

A macOS app (Swift 6, SwiftUI, macOS 14+) that scans the disk and suggests cleanups. It only suggests: the user confirms every deletion, and files go to the Trash, never permanently deleted. Open source (MIT).

## Folder layout

- `Packages/DiskEngine/`: SwiftPM library with all logic (scanning, rules, analyzers, cleanup). No UI code. Tests in `Tests/DiskEngineTests`.
- `App/Sources/`: SwiftUI app (views and view models only). Tests in `App/Tests`.
- `project.yml`: XcodeGen spec. Add targets, sources and settings here.
- `docs/research/`: sourced research notes. Read the relevant one before using an Apple API (`apis.md`) or touching CI (`ci.md`).
- `.github/workflows/ci.yml`: CI.

Never hand-edit or commit `*.xcodeproj` / `project.pbxproj`; it is generated by `xcodegen generate`.

## Safety rules (non-negotiable)

1. **Only `CleanupEngine` may delete or move files.** No other type, view model, analyzer or script may call `trashItem`, `removeItem`, `moveItem` on user files or shell out to `rm`.
2. Cleanup goes through the hard denylist, re-checks that the file still exists with the same size and modification date, refuses while the matching app is running, moves to Trash, and writes a JSONL log.
3. Analyzers and the scanner are read only.
4. Tests may only create, read and delete files inside a temp folder they created (for example `FileManager.default.temporaryDirectory` plus a UUID). Never touch the real home folder, `/Library`, or any real user path. Use fixture trees and a fake home folder.

## Workflow

- **One task per PR**, off `main`, using the task ID from the plan's Build tasks tab (title it like "Add FileNode model (T06)"). Do not mix tasks.
- Code PRs include tests for the code they add. Keep changes to what the task needs.
- Cloud threads run on Linux without Xcode. Never claim a build works unless CI ran it. CI (macos-26, Xcode 26.6) must be green before merge.
- Pin runner labels (`macos-26`); use `actions/checkout@v5`.

## Commands (on a Mac or in CI)

```
swift test --package-path Packages/DiskEngine
xcodegen generate
xcodebuild test -project DiskOptimizer.xcodeproj -scheme DiskOptimizer -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO
```

## Style

Swift 6 strict concurrency: make model types `Sendable`, prefer `async`/`await` and actors over locks. Use plain-English reasons in user-facing text.
